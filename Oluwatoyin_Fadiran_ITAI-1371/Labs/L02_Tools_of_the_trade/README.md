# Lab 02: Tools of the Trade

## Overview
Introduction to essential ML tools and libraries. Set up your development environment, work with the Iris dataset, and create your first data visualizations.

## Learning Objectives
- Set up Jupyter Notebook, Google Colab, or VS Code environments
- Import and use Python libraries (Pandas, NumPy, Matplotlib, Scikit-learn)
- Load and explore datasets
- Create data visualizations
- Practice Markdown documentation

## What's Covered
1. **Environment Setup**: Tool overview and installation options
2. **Dataset Exploration**: Loading and examining the Iris dataset (150 samples, 4 features, 3 species)
3. **Visualization**: Creating scatter plots and bar charts with Matplotlib
4. **Data Operations**: Statistical analysis and grouping with Pandas
5. **GitHub Basics**: Version control and documentation best practices

## Quick Start

**Google Colab** (Recommended):
- Upload `L02_OluwatoyinFadiran_ITAI1371.ipynb` to [colab.research.google.com](https://colab.research.google.com)

**Local Setup**:
```bash
pip install jupyter pandas numpy matplotlib scikit-learn

```

**VS Code**:
- Install Python and Jupyter extensions, then open the `.ipynb` file
