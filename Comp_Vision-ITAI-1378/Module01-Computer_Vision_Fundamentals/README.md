# Image Processing Lab: From Pixels to Perception

## Problem Statement
Understanding how computers represent and process images is fundamental to computer vision. This project explores the bridge between digital image representation and the mathematical operations that transform raw pixel data into meaningful visual information.

## Approach
- Implemented fundamental image processing operations from scratch using NumPy
- Applied traditional computer vision techniques using OpenCV and Pillow libraries
- Explored core operations: point operations (brightness, contrast), neighborhood operations (filtering, convolution), and geometric transformations
- Built hands-on understanding of digital image representation as numerical matrices

## Results
- Successfully implemented custom image processing algorithms
- Demonstrated understanding of RGB color channels and grayscale conversion
- Applied various image transformations including filtering, edge detection, and morphological operations
- Created visualizations showing before/after comparisons of image processing techniques

## Key Findings
- Images are fundamentally 3D numerical arrays (height × width × channels)
- Simple mathematical operations on pixel values create powerful visual effects
- Neighborhood operations (convolution) form the foundation for modern CNN architectures
- Traditional image processing techniques remain relevant for preprocessing in AI pipelines

## Technologies Used
- **Python 3.8+**
- **NumPy** - Matrix operations and numerical computing
- **OpenCV** - Traditional computer vision operations
- **Pillow (PIL)** - Image loading and basic transformations
- **Matplotlib** - Visualization and plotting

## How to Run
